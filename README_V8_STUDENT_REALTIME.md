# V8: аккаунты учеников, моментальные обновления, сохранение места

## Что исправлено

1. Ошибка `new row violates row-level security policy for table "student_credentials"` исправлена через безопасные Supabase RPC-функции.
2. Учеников можно создавать из ЛК преподавателя: имя входа + пароль задаёт преподаватель.
3. Изменения обновляют текущий раздел сразу после действия.
4. Добавлена Realtime-подписка: изменения из другой вкладки/устройства подтягиваются без ручной перезагрузки.
5. После перезагрузки сайт возвращает пользователя на последнюю открытую страницу и пытается восстановить позицию прокрутки.

## Что сделать

1. Заменить `index.html` в GitHub.
2. Выполнить в Supabase SQL Editor файл:

```sql
supabase_student_login_realtime_v8.sql
```

3. Дождаться деплоя Vercel.
4. Открыть сайт с жёстким обновлением: `Cmd + Shift + R` / `Ctrl + Shift + R`.
5. Войти как преподаватель и открыть: `ЛК преподавателя → Ученики`.
6. Создать ученика через форму `Создать ученика и доступ`.

## Важно

Если преподавательский аккаунт не имеет роли `admin` или `teacher` в таблице `profiles`, RPC-функции не дадут создавать логины учеников. В таблице `profiles` у твоего Supabase Auth пользователя должно быть:

```text
role = admin
```

или

```text
role = teacher
```
