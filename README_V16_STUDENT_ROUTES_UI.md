# v16 — стабильное меню, выход, ссылки и вход учеников

## Что изменено

1. Боковое меню снова всегда остаётся карточками с закруглениями и стрелками.
2. Кнопка выхода доступна в сайдбаре и в плавающей панели профиля.
3. Пункты бокового меню стали настоящими ссылками: их можно открыть в новой вкладке через Cmd/Ctrl+Click или контекстное меню.
4. Вход ученика работает через RPC `student_login_by_password_v16` без чтения таблицы паролей напрямую.
5. SQL v16 создаёт совместимые функции v16, v15 и старые имена RPC, чтобы старый код не ломался.

## Что заменить

Загрузите в GitHub:

- `index.html`
- `vercel.json`
- `supabase_student_login_routes_v16.sql`
- `README_V16_STUDENT_ROUTES_UI.md`

## Что выполнить в Supabase

Откройте Supabase → SQL Editor → New query и выполните весь файл:

`supabase_student_login_routes_v16.sql`

После этого проверьте, что в таблице `profiles` у вашего аккаунта стоит:

- `role = admin`

или

- `role = teacher`

## Проверка входа ученика

1. Откройте `/teacher/students`.
2. Создайте ученика с логином и паролем.
3. Выйдите из профиля.
4. Откройте `/login`.
5. Введите логин и пароль ученика.
6. Должен открыться `/student`.

## Проверка многостраничности

Откройте напрямую в новой вкладке:

- `/teacher/students`
- `/teacher/schedule`
- `/booking`
- `/cases`
- `/reviews`

Vercel должен отдавать сайт без 404 благодаря `vercel.json`.
