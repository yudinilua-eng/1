# v6 — Yandex materials + optimized CRM

Что изменилось:

1. Google-синхронизация убрана из интерфейса и из проекта.
2. Добавлена личная ссылка на Яндекс.Диск для каждого ученика: `student_profiles.yandex_folder_url`.
3. В ЛК ученика показывается карточка «Моя папка с материалами», если ссылка указана.
4. В ЛК преподавателя активированы формы для отзывов, кейсов и примеров материалов.
5. Раздел «Google-интеграции» заменён на «Материалы Яндекс».
6. Добавлена оптимизация: кэширование загрузки данных ЛК, debounce поиска учеников, меньше лишних перерендеров.
7. Исправлена фактическая ошибка в блоке контента преподавателя, из-за которой раздел «Отзывы и кейсы» мог падать.

## Как установить

1. Загрузить файлы архива в GitHub.
2. В Supabase SQL Editor выполнить `supabase_yandex_materials_v6.sql`.
3. Дождаться деплоя Vercel.
4. Открыть сайт с жёстким обновлением: Cmd/Ctrl + Shift + R.
5. В ЛК преподавателя открыть «Ученики» и заполнить поле «Личная Яндекс-папка».

## Проверка

- ЛК преподавателя → Ученики: создать ученика со ссылкой на Яндекс.Диск.
- ЛК ученика: должна появиться карточка «Моя папка с материалами».
- ЛК преподавателя → Материалы: добавить ссылку на файл или папку.
- ЛК преподавателя → Отзывы и кейсы: добавить отзыв, кейс и пример материала.
- Боковое меню → Материалы Яндекс: проверить инструкцию и быстрые действия.
