# V12 Booking Wizard

Изменения:

- Расписание и список свободных слотов на странице записи теперь скрыты при открытии страницы.
- Блок расписания появляется только после прохождения шагов: предмет → цель → формат → время.
- Слоты загружаются только на шаге выбора времени, чтобы не показывать пустой календарь и не делать лишние запросы к Supabase.
- При возврате на предыдущие шаги календарь снова скрывается.
- Если пользователь пришёл с карточки предмета на главной странице, предмет подставляется автоматически, но расписание всё равно открывается только после выбора цели и формата.
