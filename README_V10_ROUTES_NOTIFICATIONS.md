# v10 — маршруты, уведомления и синхронизация ЛК

## Что исправлено

- Ошибка `Cannot read properties of null (reading 'value')`: добавлен null-safe слой для старых и новых форм.
- Клики по боковому меню открывают реальные URL: `/teacher/students`, `/teacher/notifications`, `/student`, `/booking` и т.д.
- После входа кнопка «Войти в ЛК» становится «Мой профиль».
- Добавлен центр уведомлений преподавателя: запросы учеников, заявки, ДЗ на проверке, оплаты.
- Запросы на перенос из ЛК ученика синхронизируются с ЛК преподавателя.
- Одобрение переноса меняет слот и сразу обновляет данные у ученика.
- Убрана прямая проверка таблицы паролей учеников в браузере: вход идёт через RPC.

## Установка

1. Замените в GitHub `index.html`.
2. Добавьте `supabase_platform_v10_notifications_routes.sql` и выполните его в Supabase SQL Editor.
3. Убедитесь, что в репозитории есть `vercel.json`.
4. Дождитесь деплоя Vercel.
5. Очистите кэш сайта: `Cmd + Shift + R` / `Ctrl + Shift + R`.

## Проверка

- Откройте `/teacher/students` напрямую.
- Создайте ученика и пароль.
- Войдите учеником через `/login`.
- В ЛК ученика создайте запрос на перенос.
- Откройте `/teacher/notifications` — запрос должен появиться там.
- Одобрите запрос — слот должен обновиться в ЛК ученика.
