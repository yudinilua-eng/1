# v7 — вход учеников по имени и паролю

## Что изменилось

- Google-привязки нет.
- Ученик входит по имени и паролю, которые преподаватель задаёт в ЛК.
- В ЛК преподавателя → «Ученики» появилась форма «Создать ученика и вход».
- У каждого ученика можно указать личную Яндекс-папку.
- Исправлены частые ошибки `Cannot read properties of null (reading 'value')` при сохранении материалов/тем/ДЗ.

## Что выполнить в Supabase

Откройте Supabase → SQL Editor → New query и выполните файл:

```text
supabase_student_login_v7.sql
```

Он создаёт таблицу:

```text
student_credentials
```

В ней хранятся логины учеников и SHA-256 хэши паролей.

## Как создать вход ученику

1. Откройте сайт.
2. Войдите как преподаватель.
3. Перейдите: ЛК преподавателя → Ученики.
4. Заполните:
   - имя ученика;
   - имя для входа, например `ivan_8class`;
   - пароль;
   - Яндекс-папку.
5. Нажмите «Создать доступ ученику».
6. Передайте ученику имя входа и пароль.

## Как входит ученик

1. Открывает страницу «Вход».
2. Выбирает «Вход ученика».
3. Вводит имя и пароль.
4. Попадает в ЛК ученика.

## Важно про безопасность

Это рабочий MVP-вариант для персональной платформы. Для публичной платформы с большим количеством пользователей лучше вынести проверку пароля в Supabase Edge Function с `service_role`, чтобы таблица с хэшами не была доступна из браузера.
