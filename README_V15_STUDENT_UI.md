# v15 — стабильное добавление учеников и оптимизация интерфейса

## Что изменено

- Форма добавления ученика полностью заменена на одну актуальную форму.
- Email больше не обязателен: вход ученика идет по логину и паролю, которые задает преподаватель.
- Добавлена генерация логина из имени и генерация пароля.
- После создания ученик сразу появляется в списке без ручной перезагрузки.
- Карточки учеников стали информативнее: логин, предмет, контакт, статус, Яндекс-папка, заметки.
- Добавлена более стабильная RPC-функция `teacher_create_student_access_v15`.
- Интерфейс ЛК стал компактнее: обновлены карточки, поля, кнопки, фокус-состояния и адаптивность.

## Что загрузить в GitHub

- `index.html`
- `supabase_student_create_v15.sql`
- `README_V15_STUDENT_UI.md`

## Что выполнить в Supabase

Откройте Supabase → SQL Editor → New query и выполните содержимое файла:

`supabase_student_create_v15.sql`

## Важно

У аккаунта преподавателя в таблице `profiles` должно быть:

`role = admin`

или

`role = teacher`
