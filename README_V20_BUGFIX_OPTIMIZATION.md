# v20 — bugfix и оптимизация

Что сделано:

1. Добавлен безопасный слой для старых форм: отсутствие поля больше не вызывает `Cannot read properties of null (reading 'value')`.
2. Убрано дублирование красных уведомлений об одной и той же ошибке.
3. Ученический кабинет стал устойчивее к ошибкам Supabase-связей: данные подтягиваются простыми запросами и собираются на клиенте.
4. Переходы по меню сохранены как полноценные ссылки, их можно открывать в новой вкладке.
5. Уменьшена нагрузка от постоянных перерисовок публичной навигации: вместо частого цикла добавлен MutationObserver и редкий fallback.
6. Улучшены отступы, фокус-состояния, карточки, пустые состояния, hover-анимации и адаптивность.
7. Добавлена защита от горизонтального переполнения и наложения блоков.

SQL выполнять не нужно, если уже выполнен v18/v17. Если не работает вход учеников или смена пароля — выполните `supabase_platform_v18_student_theme_password.sql` и `supabase_platform_v17_final.sql`.
