# v11 — очистка дублей и стабилизация ЛК

Что изменено:

1. Из обзора ЛК преподавателя удалены старые формы добавления ученика, материалов, ДЗ, слотов и оплат. Обзор теперь содержит только карточки-переходы.
2. Рабочие действия оставлены только в отдельных разделах:
   - /teacher/students
   - /teacher/materials
   - /teacher/homework
   - /teacher/homework-review
   - /teacher/schedule
   - /teacher/finance
   - /teacher/payments
   - /teacher/content
   - /teacher/notifications
3. Убран старый v7-патч авторизации, который мог конфликтовать с новой системой входа учеников.
4. Добавлен v11-патч входа: ученик входит через RPC по логину/паролю, преподаватель — через Supabase email/password.
5. Добавлена страховка от старого кэша: если браузер подтянет старый HTML, старые формы внутри обзора ЛК будут удалены на клиенте.
6. Текст про Google Calendar заменён на нейтральный текст про расписание в ЛК.

- index.html
- vercel.json
- supabase_platform_v11_cleanup.sql
