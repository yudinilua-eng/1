# v17 — финальная чистка интерфейса и входа учеников

## Что исправлено

- убрана дублирующаяся кнопка входа из бокового меню;
- верхняя кнопка стабилизирована: без мигания, текст один — «Личный кабинет» / «Мой профиль»;
- плавающая кнопка профиля больше не «болтается»: заменена на компактную верхнюю панель;
- стрелки в боковом меню выровнены по тексту;
- боковое меню больше не должно превращаться в прямоугольные блоки;
- вход ученика теперь получает карточку через RPC `student_login_full_v17`, а не через прямой select, который мог блокироваться RLS;
- в карточке ученика можно видеть логин, статус доступа, менять логин и задавать новый пароль;
- смысловые тексты в «Почему со мной» и FAQ исправлены: больше нет противоречий про бесплатную/платную диагностику;
- ссылки бокового меню остаются настоящими ссылками, их можно открыть в новой вкладке.

## Что загрузить

Замените в GitHub:

- `index.html`
- `vercel.json`

Добавьте и выполните в Supabase SQL Editor:

- `supabase_platform_v17_final.sql`

## Проверка

1. Откройте `/teacher/students`.
2. Создайте ученика с логином и паролем.
3. В карточке ученика проверьте блок «Данные для входа».
4. Нажмите «Логин» и измените логин.
5. Нажмите «Новый пароль» и задайте пароль.
6. Выйдите из профиля.
7. Откройте `/login` и войдите учеником.
8. Должна открыться `/student` без ошибки «Карточка ученика не найдена».
