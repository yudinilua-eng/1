# v13 — заявки, статусы слотов и безопасные формы

Что изменено:

1. После отправки заявки на конкретный слот слот получает статус `pending` и на публичной странице показывается как «Потенциально занят — ждёт подтверждения».
2. После подтверждения преподавателем слот получает статус `confirmed` и исчезает из публичного расписания.
3. После отклонения заявки слот снова получает статус `open` и возвращается в расписание.
4. Карточки заявок в ЛК преподавателя стали информативнее: контакт, направление, формат, дата заявки, слот, комментарий, быстрые действия.
5. Ученические запросы на перенос/продление/вопросы отправляются безопасно и обновляются в ЛК преподавателя через realtime.
6. Убраны падения старых обработчиков с ошибкой `Cannot read properties of null (reading 'value')`.
7. При кликах по закрытым преподавательским разделам сайт больше не перебрасывает молча на авторизацию: показывает уведомление и оставляет на текущем месте.

SQL менять не нужно, если уже выполнялся v10/v11 SQL. Используются существующие таблицы `slots`, `booking_requests`, `lesson_requests`, `notification_events`.
