# v18 — ЛК ученика, пароль, интерфейс и прогресс

## Что изменилось

- Ученик может сам сменить пароль в личном кабинете.
- Преподаватель видит актуальный пароль в карточке ученика.
- Добавлена инфографика прогресса по ДЗ: выполнено, в работе, проверено, средний результат.
- Ученик может выбрать оформление ЛК: спокойное, голубое, мятное, тёплое.
- Боковое меню восстановлено: видны названия блоков и стрелки на уровне текста.
- Убрана оранжевая дублирующая кнопка профиля, если уже есть верхняя панель профиля.
- Увеличены внутренние отступы в ячейках, карточках, полях и таблицах.
- Интерфейс стал мягче: больше воздуха, скруглений, понятная визуальная иерархия.

## Что выполнить

1. Заменить в GitHub:
   - `index.html`
   - `vercel.json`

2. Выполнить в Supabase SQL:
   - `supabase_platform_v18_student_theme_password.sql`

3. После деплоя сделать жёсткое обновление страницы:
   - Mac: `Cmd + Shift + R`
   - Windows: `Ctrl + Shift + R`

## Важно про пароли

По просьбе владельца платформы актуальный пароль ученика сохраняется в таблице `student_credentials.password_plain`, чтобы преподаватель мог видеть его в карточке ученика.
Это удобно для персональной платформы, но менее безопасно, чем режим, где пароль можно только сбросить. Не публикуйте доступ к Supabase и не выдавайте права посторонним.
